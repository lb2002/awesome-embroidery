## Software

### Free

- [Ink/Stitch](https://inkstitch.org) - An open-source machine embroidery design platform based on [Inkscape](https://inkscape.org).
- [OpenStitch Studio](https://github.com/lb2002/openstitch) - Standalone open-source digitizing app (Windows/macOS/Linux) with auto-digitizing, satin columns, a small-lettering font and export to DST, PES, JEF, EXP and VP3.
